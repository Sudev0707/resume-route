# ResumeRoute - Advanced React Native Job Tracker & Resume Manager

## Project Overview
**ResumeRoute** is a production-ready, **cross-platform mobile application** built with **React Native 0.84** and **TypeScript**, designed to streamline **job application tracking** and **resume management** for career professionals. This sophisticated app features **Firebase backend integration**, **secure file storage**, and **modern navigation architecture**, delivering a seamless experience on both **Android** and **iOS** platforms.

## Key Features & Technical Implementation
- **Full-Stack Architecture**: React Native frontend + Firebase Firestore backend with real-time data synchronization
- **Authentication & Security**: Firebase Auth (email/password + verification) with granular Firestore security rules
- **Cloud Storage**: Firebase Storage for secure resume uploads (PDF support) with automatic CDN delivery
- **Advanced Navigation**: React Navigation v7 with Native Stack & Bottom Tabs (react-navigation/native-stack, bottom-tabs)
- **Component-Driven UI**: 50+ reusable TypeScript components (Card, FloatingButton, Header, Input, Toast) with custom Poppins font system
- **File Handling**: react-native-pdf, react-native-blob-util for PDF viewing and file management
- **State Management**: React Context API with custom hooks (useJobs, useResumes) for optimized data fetching
- **Offline-First**: AsyncStorage integration with fallback mock data for resilient UX
- **Performance Optimized**: Metro bundler, React Fast Refresh, SplashScreen, SafeAreaContext
- **Cross-Platform Excellence**: Dual Android/iOS builds with platform-specific optimizations

## Data Architecture
```
Firestore Collections:
├── users/{userId} - Profile data
├── jobs/{jobId}  - Job applications w/ status tracking
└── resumes/{resumeId} - Resume metadata + file URLs

Firebase Storage:
└── resumes/{userId}/{timestamp_filename.pdf}
```
